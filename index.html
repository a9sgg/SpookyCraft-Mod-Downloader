ربط CurseForge

CurseForge API يحتاج مفتاحاً معتمداً. لا تضع المفتاح داخل index.html العام. اربط الموقع بوسيط آمن مثل Cloudflare Worker يخزن المفتاح كـ Secret.

الوسيط يستقبل query وgameVersion وloader ويعيد JSON بالشكل {data:[{id,name,summary,logo:{url},links:{website},downloadCount}]}. لازم يطبّق فلاتر اللعبة والـLoader باستخدام API الرسمي.
